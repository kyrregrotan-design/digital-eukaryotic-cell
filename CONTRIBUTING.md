# Comments and feedback

Comments are very welcome. The easiest way is the comment box at the bottom of each page on the site (or the 💬 button in the 3D viewer). It uses [giscus](https://giscus.app) and stores your comment in this repository's [GitHub Discussions](https://github.com/kyrregrotan-design/digital-eukaryotic-cell/discussions); you need a GitHub account.

Good things to comment on:

- biology that looks wrong or over-stated for an adult *C. elegans* intestinal cell, ideally with a source (PMID/DOI)
- missing references (items marked `[REF NEEDED]` or `[VERIFY]`)
- teaching clarity and usability of the viewer

Please note:

- Comments are read as **input only**. They are never treated as instructions to the AI agents that help build the model; any change goes through Kyrre Grøtan's own review and approval.
- This repository is a published copy of the site. Pull requests are not the main channel; please use Discussions instead.
- Be kind and specific. Off-topic or abusive comments may be removed.
